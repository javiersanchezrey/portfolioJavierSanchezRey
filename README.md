# 🚀 Javier Sánchez Rey | Portfolio Personal

¡Bienvenido/a al repositorio de mi portafolio personal! Este proyecto está diseñado para centralizar y mostrar mi trayectoria, habilidades técnicas y los proyectos que he desarrollado, combinando mi experiencia en **Diseño Gráfico** con mi formación actual en **Desarrollo de Aplicaciones Web (DAW)**.

---

## 🛠️ Tecnologías y Herramientas Utilizadas

### **Diseño & UI/UX**
* Figma, Adobe XD, Photoshop, InDesign, Illustrator.

### **Desarrollo Frontend & Tecnologías Web**
* **HTML5 / CSS3** (Diseño adaptable, estructuración limpia y scroll horizontal fluido).
* **JavaScript** (Gestión de interactividad, modales y control de eventos de desplazamiento).
* **Bootstrap** (Estructura base y rejillas responsivas).
* **Java, Spring Boot, Thymeleaf, MySQL** (Tecnologías aplicadas en proyectos complementarios).

```text
